# 数据怎么下载

数据不放在仓库里，得自己下。

数据集是天池 649，淘宝用户行为数据，链接：https://tianchi.aliyun.com/dataset/649

987,994 名用户，100,150,807 条行为记录，2017-11-25 到 2017-12-03。文件是 `UserBehavior.csv`，大概 1 亿行，解压后 3-4 GB，记得留磁盘空间。

字段就 5 列：`user_id`、`item_id`、`category_id`、`behavior_type`（pv / buy / cart / fav）、`timestamp`（秒级时间戳）。许可 CC BY-NC-SA 4.0，只能学习用，不能商用。

## 下载

1. 打开上面那个天池链接，用淘宝账号登录，没有就先注册一个。
2. 点下载，解压后把 `UserBehavior.csv` 放到 `data/raw/`。
3. 文件挺大的，下载要一阵子，别中途关浏览器。

## 抽样

原始文件 1 亿行，直接全量读很慢，内存也不够。`notebooks/01_data_cleaning_eda.py` 会先读入、清洗，再用固定种子 42 抽大概 1,000,000 行做后面的分析。报告里写数字的时候要写明是抽样约 100 万行，别写成全量 1 亿行的数。

电脑内存小的话（8 GB 以下），可以先只取前 1,000,000 行练手，在脚本里把抽样数改小就行，改完记得在报告里写改后的行数。

## 下完检查一下

`data/raw/` 里应该有这个文件：

```text
UserBehavior.csv
```

然后回项目根目录跑：

```bash
python notebooks/01_data_cleaning_eda.py
```

脚本会先打印原始行数、清洗掉了多少超范围时间戳、抽样后剩多少行，再出每天的 PV/UV、行为分布、类目 Top 和小时趋势图。
