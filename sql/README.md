# SQL 业务查询（T1-3）

11 条业务 SQL 查询 + SQLite 运行脚本。所有结果均在样本数据上实测得出，
与 Python 版（`notebooks/02_funnel_rfm_analysis.py`）逐项交叉核对一致。

## 运行方法

```bash
# 在仓库根目录运行（只需 Python 标准库，无需安装任何依赖）
python sql/run_sqlite.py
```

- 数据：`outputs/taobao_clean_sample.csv`（10,053 名用户的整群抽样，
  总体 987,994 用户的 1.02%，1,009,774 行；时间窗口为北京时间
  2017-11-25 至 2017-12-03，双 12 预热期 9 天）。
- 口径声明：比例类指标可推广，规模类数字（人数、行数）不得直接等同总体规模。
- 全量运行约 13 秒（载入样本 + 10 条查询，含索引构建）。

## 查询清单

| # | 业务问题 | 口径要点 |
|---|---|---|
| Q1 | 每日 PV / UV / 购买人数与购买转化率 | 按 `date` 分组；转化率分按 PV 与按 UV 两种 |
| Q2 | 覆盖漏斗各环节人数与转化率（口径 A） | 独立用户数，不要求行为先后顺序；cart 与 fav 并列 |
| Q3 | 时序漏斗 pv → 意向 → 购买（口径 B） | 严格按时间先后；1,510 名购买用户未满足该路径（767 人无意向记录，743 人顺序不满足） |
| Q4 | 次日留存率 | 留存率 = \|当日 ∩ 次日\| / \|当日\|；12-03 无次日，自动排除 |
| Q5 | R+F 用户分层人数（无 M） | 观察日 2017-12-03；R 维度在 9 天窗口内已退化，分层实际是单维 F |
| Q6 | Top 10 类目 | 按 PV 排序，窗口函数 `RANK()` |
| Q7 | 分时段（hour 0–23）PV 与购买分布 | 按 `hour` 分组 |
| Q8 | 购买次数分布（0 次 / 恰好 1 次 / ≥2 次） | 与 R+F 分层呼应 |
| Q9 | 意向到购买：两种口径对照 | 宽松口径（任何意向）vs 严格时序口径（= Q3 第二步→第三步） |
| Q9b | 未满足完整时序路径的购买用户分流 | 无意向购买 767 人 vs 顺序不满足 743 人，两类不得混称“直接购买” |
| Q10 | 日环比：每日 PV 与购买人数的 LAG 日增长率 | 窗口函数 `LAG()` |

### Q3：时序漏斗（口径 B，人数）

| step | users | step_conv_from_prev | overall_conv_from_pv |
|---|---|---|---|
| pv | 10,008 | 1.0000 | 1.0000 |
| pv_to_intent | 8,583 | 0.8576 | 0.8576 |
| intent_to_buy | 5,336 | 0.6217 | 0.5332 |

“整体转化率 53.3%”仅指完成完整路径的用户占比。1,510 名购买用户
（22.1%）未满足完整时序路径，不得统称为“直接购买”：其中 767 人在窗口内
无任何加购/收藏记录（无意向购买）；743 人有意向行为但顺序不满足——
625 人首次购买在首次意向之前，88 人首次意向在首次浏览之前，
30 人无浏览记录。购买记录层面：5,010 条购买记录（25.0%）不在完整时序
路径内，其中 4,589 条在购买前无任何意向记录。

漏斗口径：当前漏斗是用户级、跨商品的行为顺序，不等于真实商品交易路径：
5,336 名完整路径购买用户中，仅 2,797 人（52.4%）至少购买过一件意向商品，
2,539 人（47.6%）购买的全部是未意向过的商品。

### Q7：分时段购买转化

- PV 最高时段：21:00（75,896）、22:00（75,747）、20:00（67,293）。
- 购买转化率（购买次数 / 浏览次数）最高时段：10:00（3.03%）、
  11:00（2.73%）、12:00（2.78%）；凌晨 0–5 点流量与转化均最低
  （5:00 转化率 1.46% 为全天最低）。
- 业务含义：上午 10–12 点是转化效率最高的窗口，晚间 20–22 点是
  流量最大的窗口，两者错位，触达策略应分时段设计。

### Q9：意向到购买——两种口径对照

| caliber | intent_users | buyers | buy_rate |
|---|---|---|---|
| strict_seq（严格时序，= Q3） | 8,583 | 5,336 | 0.6217 |
| any_intent（任何意向行为） | 8,671 | 6,079 | 0.7011 |

两种口径相差 7.94pp：宽松口径计入了意向发生在购买之后或无先后
关系的用户；汇报意向转化率时须注明用的是哪一种口径。

未满足完整时序路径的购买用户（1,510 人）分流：
无任何意向记录 767 人，有意向但顺序不满足 743 人（625 人首次购买在
首次意向之前，88 人首次意向在首次浏览之前，30 人无浏览记录）。
3,247 名意向用户在首次意向之后未购买，其中 683 人在首次意向之前已购买过，
2,564 人在窗口内从未购买——不得把 3,247 人直接称为“最终未购买用户”。

### Q10：日环比（LAG）

- 11-25→12-01 期间 PV 日环比在 -4.29% ~ +3.63% 之间窄幅波动；
- 12-02（周六）PV 环比 **+27.34%**、购买人数环比 **+28.98%**，
  为 9 天内最大单日跳升；12-03 环比基本持平（PV -0.19%）。

## 三率区分（汇报时必须分清）

| 指标 | 定义 | 本样本数值 |
|---|---|---|
| 事件次数比 | 购买次数 / 浏览次数 | 全样本 2.21%（20,018 / 906,054）；按类目/时段的转化率也是事件次数比 |
| 用户覆盖率 | 发生过某行为的用户 / 浏览用户 | 购买覆盖率 68.4%（6,846 / 10,008） |
| 真实路径转化率 | 完成完整时序路径的用户 / 浏览用户 | 53.3%（5,336 / 10,008），须注明 1,510 名购买用户未满足该路径 |

三者口径不同，不得混用；“购买转化率”默认指用户覆盖率（68.4%，9 天累计口径）。
